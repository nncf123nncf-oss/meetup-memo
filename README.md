# 交流会のあの人メモ（meetup-memo）

交流会で会った人を30秒で残し、連絡しそびれている人を一覧の一番上に出す1ページの道具です。

- 記録はお使いの端末のブラウザ（localStorage）にだけ保存し、外部に送信しません
- バックアップとして、ファイルへの書き出し・読み込みができます（iPhone・iPadは共有シート、使えない場合はテキストを長押しでコピー）
- 名刺の写真・連絡先は扱いません。文字の読み取りもしません

100日100プロダクトチャレンジ Day075。

## 検算

- `node source/core-test.js` 判定・検索・入力・日付・iOS判定・バックアップの検算
- `node source/check.js <出力フォルダ>` 確認用の実画面と375pxの矩形計測（Chrome headless）
